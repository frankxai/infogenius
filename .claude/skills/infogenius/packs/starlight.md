# Style pack: starlight

Source: `frankxai/starlight-design-intelligence@851a11b`, `brand-image-system/runtime/brands/sis/brand-pack.json` (brand id `sis`). If that file changes, regenerate this pack; do not edit colors here by hand.

## Use when
The visual explains agent operations, evaluation or provenance for Starlight Intelligence Systems readers (AI platform leaders, operators, evaluation and governance teams).

## Colors
The pack marks these as operator-mode references whose site adoption is unverified. Use them for operator and evidence visuals; check `brand-packs/sis/BRAND.md` for other modes.
- Void `#0a0a0b`
- Space `#111113`
- Signal `#6366f1`
- Evidence `#a5b4fc`

## Direction
- Show the trace: the steps an agent took, with inputs and outputs.
- Make confidence inspectable: show what a claim rests on.
- Keep it calm and stable to read.

## Never
- Radiant particle fields, hype science fiction
- Moving dashboards or generic dashboard filler
- Uncited confidence claims, black-box intelligence
- Phrases: "sentient system", "autonomous revolution", "magic intelligence"

## Prompt lines to add
```text
PALETTE: void #0a0a0b, space #111113, signal #6366f1 for the active path, evidence #a5b4fc for cited sources.
COMPOSITION: a legible trace or evidence stack; every node labeled with what it did; no particles, no glow fields.
```
